      عملیات‌های پایه

      عملیاتپارامترهاکاربرد
      navigateurl, waitهدایت به آدرس وب
      clickselector, waitکلیک روی عنصر
      typeselector, text, clearوارد کردن متن (پشتیبانی از {{var}})
      type_humanselector, text, char_delayتایپ کاراکتر به کاراکتر (ضد تشخیص ربات)
      select_optionselector, valueانتخاب از منوی کشویی

      عملیات‌های انتظار

      عملیاتپارامترهاکاربرد
      waitsecondsتوقف زمانی
      wait_for_elementselector, timeoutصبر تا ظاهرشدن عنصر
      wait_element_goneselector, timeoutصبر تا ناپدیدشدن عنصر (مثلاً لودینگ)
      wait_for_humanprompt, success_selector, timeoutتوقف برای دخالت کاربر (کپچا، تأیید دو مرحله‌ای)

      استخراج و پیمایش

      عملیاتپارامترهاکاربرد
      extract_textselector, attribute, store_asاستخراج متن یک عنصر
      extract_listselector, attribute, store_asاستخراج لیست از چند عنصر
      crawl_linksselector, store_asجمع‌آوری لینک‌های صفحه
      scrollselector, direction, amountاسکرول صفحه یا عنصر
      scroll_to_bottomselector, max_scrolls, waitپیمایش کامل تا انتها (لیست‌های نامحدود)
      screenshot—ذخیره اسکرین‌شات در پوشه output

      منطق و کنترل

      عملیاتپارامترهاکاربرد
      set_variablekey, valueتعریف متغیر (قابل استفاده با {{key}})
      evaluate_jscode, store_asاجرای JavaScript و ذخیره نتیجه
      loopcount, stepsتکرار زیرگام‌ها (متغیر {{loop_index}})
      conditionalselector, then_steps, else_stepsاجرای شرطی بر اساس وجود عنصر

      متغیرهای داینامیک

      با set_variable متغیر تعریف کنید. سپس در فیلد text از {{نام_متغیر}} استفاده کنید. مثال:

      [
  {"action": "set_variable", "key": "user", "value": "admin"},
  {"action": "type", "selector": "#login", "text": "{{user}}"}
]

      سلکتور CSS

      • #myId — شناسه
      • .myClass — کلاس
      • input[name="email"] — ویژگی
      • button[type="submit"] — دکمه ارسال
      • table tr:nth-child(2) — ردیف دوم جدول
